# PinkMint Web Studio

A responsive pink + green website-template marketplace inspired by the provided reference interface.

## GitHub Pages deployment
1. Create a new GitHub repository.
2. Upload **all files in this folder** to the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait a few minutes and open the GitHub Pages URL.

No server or database is required for the demo. Cart data is stored in the browser with localStorage.
